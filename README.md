# DSIA - Tecnicatura Ciencia de Datos

Repositorio de prácticas y actividades realizadas en la materia Desarrollo de Sistemas de Inteligencia Artificial.

## Contenido

### 01 - DeepNote
- Introducción al entorno DeepNote
- Creación de notebooks
- Manejo de archivos e imágenes

### 02 - Python Repaso
- Variables y operaciones
- Condicionales
- Bucles y listas

### 03 - Python Librerías
- Importación de librerías (NumPy, Pandas, Seaborn, Matplotlib)
- Creación y cálculo estadístico básico sobre DataFrames
- Criterios de selección de herramientas para análisis de datos

### 04 - Trabajo Práctico Integrador (TPI)
- Carga, limpieza y preparación del dataset de recorridos de **Ecobici 2024** (GCBA)
- Análisis Exploratorio de Datos (EDA) completo y contraste de hipótesis de negocio
- Implementación de modelos de **Machine Learning** aplicados al dataset de Ecobici
